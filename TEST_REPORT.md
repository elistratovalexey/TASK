# Проверка 1.3.3

Среда: Linux, Flutter 3.47.7 stable.

- `flutter analyze` — замечаний нет.
- `flutter test` — 136 тестов пройдены. В 1.3.3 добавлены: ежедневный «Ланч» 10:00–10:30 с началом и окончанием стоит на своём времени без предложения переноса, плановые задачи его обходят; следующий экземпляр сохраняет 10:00–10:30; «Факт» показывает только прошедшее; расчёт начала (по часам и по рабочему времени для оценки больше дня); форматирование (стили выделения, ввод внутри, новый текст после кнопки, сохранение и загрузка, сброс при изменении текста старой версией, ссылки, обрезка пробелов); кнопки «Рассчитать» и форматирование заметок в редакторе задачи. Скриншоты редактора базы знаний проверены в светлой и тёмной теме. В 1.3.2 добавлены: задача без галочки «Показывать на временной шкале» не планируется и не занимает время, не попадает в «План», «Факт» и сроки шкалы, столбец Excel «На шкале», галочка в редакторе и пометка в карточке. В 1.3.1 добавлены: задача с заданным началом стоит на своём времени (в том числе в выходной), плановые задачи заполняют свободное время и не пересекаются с закреплёнными, оконченная задача не закрепляется; раскладка пересекающихся и коротких блоков рядом. Шкала проверена на реальной базе пользователя (23.10.2026, МСК): все задачи с началом стоят на своём времени, сроки на флажках совпадают с задачами. В 1.3.0 добавлены: блоки плана (части, опоздание), факта (обрезка по полуночи, выполняемая задача до текущего времени), сроки дня; интерфейс шкалы (открытие по нажатию на день, заголовок и загрузка, колонки «План»/«Факт», флажок срока, линия «сейчас», перерыв, листание дней, выходной, открытие задачи по блоку, без ошибок вёрстки на 380 px). Снимки шкалы в тёмной теме проверены. В 1.2.0 добавлены: распознавание темы «СПИСОК ПОКУПОК» и магазина из темы, разбор строк письма (маркеры, количество, пересылка, подпись, запятые), объединение без повторов, запоминание покупок и магазинов без дублей, порядок подсказок по частоте, проверка данных списков, письмо → предложение без задачи и без дублей, принятие письма в существующий список, объединение списков на одну дату и магазин, интерфейс вкладки (новый список, отметка, подсказки, выбор из сохранённых), разбор письма в интерфейсе, справочники. Очистка темы теперь убирает и «Пересл.:». Снимки вкладки, редактора и окна разбора проверены. В 1.1.0 добавлены: проверка человека и списка задействованных, справочник в снимке синхронизации, короткое ФИО и скрытие удалённых, столбец Excel, выбор нескольких ФИО из списка с добавлением нового и фильтром, справочник в настройках (дубль, удаление), запись базы знаний с задействованными. Снимки карточки, редактора и окна выбора проверены. В 1.0.0 добавлены: совпадение версии с pubspec, оценка по умолчанию и формат, рабочее время и его сохранение, план (порядок по срокам, перерыв, выходные, деление на части, загрузка по дням), предложения и перенос сроков со сдвигом напоминания, фильтры экспорта по проектам/подпроектам и статусам, структура xlsx и экранирование, дата Excel, письмо с вложением (только ASCII, без разрывов слов), отправка через SMTP-настройки ящика задач, публикация/проверка/загрузка обновления с проверкой SHA-256, версия из MSIX, интерфейс календаря, планирования, экспорта, рабочего времени и редактора на узком экране. Файл xlsx дополнительно открыт в openpyxl и LibreOffice. В 0.6.0 добавлены: формат длительности, затраченное время, запрет окончания раньше начала, автоокончание при отметке выполнения и очистка при повторном открытии, начало в будущем, сброс у повторяющейся задачи, кнопка «Начать» и редактор времени. Снимки карточек и редактора в тёмной теме проверены. Новые в 0.5.0:
  - данные: цвета строк и пунктов, чек-лист записи, задача без проекта только во входящих;
  - разбор письма: тема в кодировке UTF-8/Base64 без «Fwd:», текст из HTML, PDF-вложение, одинаковый ID задачи для одного письма;
  - приём почты: письмо разрешённого отправителя → задача и перенос письма, чужое письмо не тронуто, нет дубля при сбое переноса, без разрешённых отправителей ящик не читается;
  - интерфейс: «Разобрать» — без проекта не сохраняется, выбор проекта и цвета; запись базы знаний с чек-листом и цветом.
- Снимки экранов в тёмной теме (задачи, дерево базы знаний, редактор записи) проверены визуально.

Не проверено в этой среде: реальный IMAP-сервер Mail.ru/Яндекс/Gmail, сборка Windows/MSIX и APK.

Не проверено в этой среде (1.0.0): реальная отправка через SMTP Mail.ru, открытие xlsx в Microsoft Excel, установка обновления MSIX/APK на устройствах.
